# 16クラスタ代表デッキのタイプ・カード構成

競技向け16デッキの構成は [`competitive_deck_type_summary.md`](competitive_deck_type_summary.md) を参照してください。

## 集計対象と割合の定義

- 対象: `cluster_00_representative.csv` ～ `cluster_15_representative.csv` の16デッキ
- 各CSVは入力データ内で実際に観測された60枚構築です。競技向けの `competitive.csv` は対象外です。
- カード種別割合の分母: デッキ全体の60枚
- ポケモンタイプ割合の分母: そのデッキに入っているポケモンの合計枚数
- エネルギータイプ割合の分母: そのデッキに入っているエネルギーの合計枚数
- カード名・種別・タイプ: `data/JP_Card_Data.csv` を使用
- 「主要」判定: クラスタの対戦シェアが0.5%以上

## 読み方と注意点

- 一覧のポケモン・グッズ・エネルギー割合は、各代表デッキ60枚に占める割合です。残りはサポート、スタジアム、ポケモンのどうぐ等です。
- 一覧の「エネルギータイプ」は、各デッキに採用されたエネルギーカードだけを分母にした構成です。
- ポケモンタイプ割合は、デッキ全体ではなくポケモンカードだけを分母にしています。
- `無無無` や `【ロケット団】【ロケット団】` などのエネルギータイプ表記は、カードマスターの `タイプ` 列をそのまま集計した値です。
- この文書は代表16デッキの構成を説明するものです。クラスタ全メンバーの平均構成は [`hierarchical_cluster_evaluation_16.md`](../hierarchical_cluster_evaluation_16.md) を参照してください。
