# 16クラスタ競技向けデッキのタイプ・カード構成

## 集計対象と割合の定義

- 対象: `cluster_00_competitive.csv` ～ `cluster_15_competitive.csv` の16デッキ
- 各CSVは、クラスタの最大中心性との差が0.03以内となる実在60枚構築から、補正勝率を優先して選ばれたデッキです。
- カード種別割合の分母: デッキ全体の60枚
- ポケモンタイプ割合の分母: そのデッキに入っているポケモンの合計枚数
- エネルギータイプ割合の分母: そのデッキに入っているエネルギーの合計枚数
- カード名・種別・タイプ: `data/JP_Card_Data.csv` を使用
- 補正勝率: 20試合分のクラスタ平均勝率を事前値として、少数試合の勝率を補正した値

## 読み方と注意点

- 一覧のポケモン・グッズ・エネルギー割合は各60枚デッキに占める割合です。残りはサポート、スタジアム、ポケモンのどうぐ等です。
- 一覧の「エネルギータイプ」は、各デッキに採用されたエネルギーカードだけを分母にした構成です。
- ポケモンタイプ割合は、デッキ全体ではなくポケモンカードだけを分母にしています。
- 補正勝率はクラスタ平均へ縮約した選出用指標です。単純勝率や将来環境での強さを保証する値ではありません。
- クラスタ3、4、11～15は代表デッキと競技向けデッキが同一です。
- `無無無` や `【ロケット団】【ロケット団】` などの表記は、カードマスターの `タイプ` 列をそのまま集計しています。
- 代表16デッキの構成は [`representative_deck_type_summary.md`](representative_deck_type_summary.md) を参照してください。
